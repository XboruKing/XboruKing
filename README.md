## 🚀 Projet phare

### Lm3alem — Projet de fin d'études
Plateforme web permettant aux artisans (menuisiers, mécaniciens, techniciens) de créer et gérer leurs profils professionnels.

- **Backend** : API RESTful avec Laravel, authentification sécurisée (JWT)
- **Frontend** : React.js + TypeScript, état global avec Zustand, interface shadcn/ui
- **Déploiement** : conteneurisation avec Docker, base de données PostgreSQL
